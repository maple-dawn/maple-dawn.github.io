常见问题

怎么收费？ 免费下载，全部功能可免费试用 7 天，到期不会自动扣费；之后 US$1.99 一次性永久解锁，没有订阅。购买过 1.0 的用户无需再付费，必要时点「恢复购买」。翻译使用你自己的 API Key，用量费用由对应的 AI 服务商按其价格向你收取。

在哪里获取 API Key？ 在 DeepSeek、Anthropic（Claude）、Google AI Studio（Gemini）或 OpenAI 的开发者平台注册后创建，然后在「设置 › 模型服务」中填写。

提示「尚未填写 API Key」或请求失败？ 检查 Key 是否正确、账户是否有余额，以及模型名是否可用。可以在服务详情中点「从服务商获取模型列表」验证。

怎么用电脑上的本地模型？ 在电脑上运行 Ollama 或 LM Studio 并允许局域网访问，在 App 中添加对应服务，把接口地址改成电脑的局域网 IP，例如 http://192.168.1.2:11434/v1。

我的数据会发给谁？ 只发给你授权的服务商。详见下方的隐私政策。

FAQ

How much does it cost? Transory is free to download and every feature is free for 7 days, with no automatic charge when the trial ends. After that, a one-time US$1.99 purchase unlocks it forever—no subscription. If you bought version 1.0, you already have full access; use Restore Purchases if needed. Translations use your own API key and are billed by the AI provider.

Where do I get an API key? From the developer console of DeepSeek, Anthropic (Claude), Google AI Studio (Gemini), or OpenAI. Enter it in Settings › Model Services.

It says “No API key” or requests fail? Check that the key is correct, your account has credit, and the model name is available. In the service details, tap “Fetch models from provider” to verify.

How do I use a local model on my computer? Run Ollama or LM Studio on your computer with LAN access enabled, add the matching service in the app, and set the endpoint to your computer’s LAN IP, e.g. http://192.168.1.2:11434/v1.

Who receives my text? Only the providers you authorize. See the Privacy Policy below.

よくある質問

料金はいくらですか？ ダウンロードは無料で、すべての機能を 7 日間無料でお試しいただけます。期間終了時に自動で課金されることはありません。その後は US$1.99 の買い切りで永久に解除でき、サブスクリプションはありません。バージョン 1.0 をご購入済みの方は追加料金不要です。必要に応じて「購入を復元」をタップしてください。翻訳にはご自身の API キーを使用し、利用料金は各 AI サービス提供元から請求されます。

API キーはどこで取得できますか？ DeepSeek、Anthropic（Claude）、Google AI Studio（Gemini）、OpenAI の開発者コンソールで作成し、「設定 › モデルサービス」に入力してください。

「API キーが未入力」と表示される、またはリクエストが失敗する キーが正しいか、アカウントに残高があるか、モデル名が利用可能かを確認してください。サービスの詳細画面で「提供元からモデル一覧を取得」をタップすると確認できます。

パソコン上のローカルモデルを使うには？ パソコンで Ollama または LM Studio を起動して LAN からのアクセスを許可し、アプリで対応するサービスを追加して、エンドポイントをパソコンの LAN IP（例：http://192.168.1.2:11434/v1）に変更してください。
